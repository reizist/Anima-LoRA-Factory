衣装や背景が異なる高品質な画像を15〜30枚程度用意しましょう。
Tip: Prepare 15-30 high-quality images with diverse poses and backgrounds.
💡 解像度について (Resolution):
Animaモデルは1024x1024前後での学習を推奨しています。アスペクト比はバラバラでも自動調整されます。
Resolution: 1024x1024 is recommended. Various aspect ratios are supported via buckets.

💡 タグ編集の基本ルール / Rules

LoRAに「学習させたい特徴」のタグを削除するのが基本です。削除した特徴がトリガーワードに集約されます。
@付きでトリガーワードを設定すると、学習履歴にも保存されます。
(Remove tags of features you want to train; they will merge into the trigger word. Trigger words that start with @ are also saved in the training history.)

📖 LoRAタイプ別・編集のコツ / Editing Tips

👤 キャラクターLoRA / Character:
髪色、目の色、固有の服などのタグを削除します。
(Remove hair, eyes, unique clothes etc.)
🎨 スタイルLoRA / Style:
具体的な物のタグは残し、品質タグを削除します。
(Keep object tags, remove quality tags like masterpiece.)
👗 衣装LoRA / Clothing:
その衣装を示すタグのみを削除します。
(Remove only the tags specific to the outfit.)

学習の強さ 推定: -- steps

学習の強さは、基本的に「総ステップ数」で決まります。ステップ数が多いほどキャラクターを強く覚えますが、服・絵柄・ポーズも固定されやすくなります。

総ステップ数は、だいたい 画像枚数 × Repeats × Epochs で決まります。

画像枚数を読み込むと推定ステップ数を表示します。
  • 500〜800: 軽め。まず試す時におすすめ
  • 1000〜1500: 標準。キャラをしっかり覚えたい時
  • 2000〜3000: 強め。服や絵柄も残りやすい
  • 3000以上: かなり強め。慣れてからがおすすめ

よく分からない場合は、まず 1000〜1500 ステップ前後を目安にしてください。

AdamWは学習率を自分で調整する必要があります。Prodigy / DAdaptationは学習率を自動調整してくれますが、VRAM消費がやや増え、対応パッケージのインストールが必要です。
(AdamW requires manual LR tuning. Prodigy/DAdaptation auto-tune LR, but use slightly more VRAM and require extra packages — run "Repair Environment" below after switching.)

Prodigy/DAdaptationはAdamWより多くのVRAMを使うため、VRAM不足が出る場合はこちらを有効にしてください。学習はやや遅くなります。
(Prodigy/DAdaptation use more VRAM than AdamW. Enable this if you hit out-of-memory errors. Training will be a bit slower.)

Prodigy / DAdaptationは学習率を自動計算するため、AdamWのような小さい値ではなく1.0前後を推奨します。0.0001のような値を入れると学習がほとんど進みません。
(Prodigy/DAdaptation auto-compute the effective LR, so use a value around 1.0 instead of AdamW-style small values. A value like 0.0001 will barely train at all.)

💡 初心者へのアドバイス / Advice:
基本的には「バランス」設定で問題ありません。エラーが出る場合は「低容量」を試してください。
(Balanced is usually fine. If you get errors, try Low VRAM mode.)

画像読み込みの並列数です。0が最も安定します。学習開始時に止まる場合は0のまま、速度を重視する上級者のみ2〜8に増やしてください。旧バージョンで問題なく使えていた人は8で従来通りの設定になります。
(Number of parallel image loading workers. 0 is the most stable. Advanced users can raise it to 2-8 for speed.)

学習中に画像を50%の確率で左右反転します。左右非対称なキャラクター、文字、ロゴ、片目・片側だけの特徴を学習する場合はOFFを推奨します。
(Randomly flips images horizontally during training. Leave it off for asymmetric characters, text, logos, or one-sided details.)

ONにするとタグ順を毎回入れ替えます。先頭のトリガーワードを守りたい場合は keep_tokens を1以上にします。
(Shuffles tag order during training. keep_tokens keeps the first tags fixed, usually for trigger words.)

ONにすると --min_snr_gamma を追加します。推奨値は5です。学習のバランスを整え、過学習感を少し抑えることがあります。
(Adds --min_snr_gamma. Recommended value is 5. It can improve training balance and sometimes reduce overfitting.)

--optimizer_args に渡す追加パラメータです。スペース区切りで key=value の形式で入力してください。わからない場合は空欄で構いません。
(Extra parameters passed to --optimizer_args, space-separated key=value pairs. Leave blank if unsure.)
